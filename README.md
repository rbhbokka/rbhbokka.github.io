# rbhbokka.github.io

Personal site of Kiryl Yemelyanenka, senior iOS engineer.

Hand-written HTML, CSS, and JavaScript. No framework, no build step, no dependencies.
The hero is a single WebGL2 fragment shader: an inverse stereographic projection of a
procedural graticule sphere — the math of the Metal 360° video editor I'm building,
run in reverse. If WebGL2, JavaScript, or motion is off, a static poster takes its place.
